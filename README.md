# K线手绘编辑器

**让每一根 K 线，都由你亲手画出来。**

不用导入行情数据，不用写代码 —— 在画布上拖一笔就是一根 K 线，
画完就能出技术指标、多周期复盘、截图识图和动画视频。

## 这是什么

一个**纯手绘**的 K 线工作台。市面上的图表软件都在"读行情"，它在做反过来的事：
你把脑子里的走势画出来 —— 第几根破位、哪一根放量假突破、顶部长什么样 ——
然后立刻看到它在 MACD、RSI、均线、多周期聚合下是什么样子。

适合几类人：

- 做交易复盘，想把"我看到的那段结构"复刻下来，而不是对着真实行情截图
- 写复盘笔记 / 教学材料 / 公众号配图，需要一个能出干净图片和视频的工具
- 做量化研究前的手工样本、形态标注，需要精确控制每一根的 OHLC
- 单纯想画好看的 K 线图

**完全离线**，不联网、不传数据、不需要账号。

## 快速开始

### 下载安装包

1. 打开 [Releases](https://github.com/nainai520/kline-editor/releases) 下载 `KLinePainter-v3.1.0-Setup-win64.exe`
2. 双击安装，默认装到 `%LOCALAPPDATA%\Programs\K线手绘编辑器`（**免管理员**，可改到其它盘）
3. 可选桌面 / 开始菜单快捷方式，装完直接运行；控制面板里能正常卸载

> 首次运行若被 SmartScreen 拦一下：点「更多信息」→「仍要运行」。

**运行环境**：Windows 10 / 11 x64，无需安装 Python，无需联网。
导出 MP4 需要系统里有 `ffmpeg`；没有时会自动降级为 GIF，其他功能不受影响。

## 数据模型

有一条约定贯穿整个程序，理解了它就不会踩坑：

> **日线是数据本体，周/月/年线只是"看的角度"。**

- `self._daily` 保存真实的日线序列，切换周期不改变它
- 周/月/年是按"开=区间第一根开、收=最后一根收、高/低=区间极值、量=求和"实时聚合出来的
- 因此在聚合线上做的编辑，都会**反推回日线**再重算，切回日线数据不会丢
- 保存工程、导出 CSV 时，写进去的永远是日线原数据
- 在年线空白处拖一根，会**自动往下级联生成**月 → 周 → 日，父级开收被子级精确还原

工程文件 `.kln` 是纯文本 JSON，可以直接看、直接 diff、直接备份。

## 技术实现

| 层 | 选型 | 说明 |
|---|---|---|
| 界面 | Tkinter | 设计令牌层统一配色/间距/圆角，控件走工厂函数，深浅双主题同源 |
| 图表 | matplotlib (TkAgg) | `LineCollection` / `PolyCollection` 批量绘制，百万级图元仍可拖动画布 |
| 图像 | Pillow + numpy | 启动封面用分层窗口（`UpdateLayeredWindow`）实现真实毛玻璃与圆角阴影 |
| 视频 | ffmpeg 管道 / Pillow | 按帧烘焙、直接喂 `yuv420p`，输出的就是回放看到的那一帧 |
| 打包 | PyInstaller + 自研安装器 | 单文件 exe 之外另给安装包：onedir 载荷 + AES-256-GCM 加密，装完免 %TEMP% 解压、卸载能整目录删净 |

代码规模约 1.1 万行，开发期配套 **17 组断言式测试**，
覆盖数据往返不变量、像素级 UI 配色、导出尺寸以及打包产物的端到端校验。

## 隐私与数据

- 全程本地运行，**不发起任何网络请求**
- 没有埋点、没有账号、没有云同步
- 工程文件、图片、视频全部留在你自己的磁盘上
- 唯一联网的可能：你自己把导出的图/视频发出去

## 已知限制

- 只支持 Windows（用到了 Windows 分层窗口与 DPI API）
- 截图识图对**深色底、清晰、无遮挡**的行情截图效果最好，成交量识别不到时会填 0
- AI 剧情需要自己准备 GGUF 模型文件，默认不启用
